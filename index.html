THE PROCESS

From unwanted
to useful.

01
📦

Send it

You send me something you've got that you don't need anymore. I'll first make sure it's something I can safely use.

02
💬

Talk about it

We talk about what you might like the material or object to become.

03
💡

Find an idea

If we don't know what to make, I'll come up with some possible ideas.

04
✓

Check first

We'll make sure the idea is okay before I start making it. If I'm unsure about a material or project, I'll discuss it with someone experienced before going ahead.

05
🛠️

Make it

I create the new item using the agreed idea or my own design.

06
✨

Give it a new purpose

Something that might have been forgotten or thrown away gets another chance to be useful.

NOT SURE WHAT TO MAKE?

No idea? No problem.

Sometimes you have a material but no idea what it could become. That's where I can help. I'll think of different possibilities and we can choose an idea together.

MATERIALS

What can be given

I'm starting with materials that are clean, safe and suitable for creative projects. If you're not sure whether something could be useful, you can always ask.
